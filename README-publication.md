# Bible en un an par genres

Décompressez ce dossier et publiez tous ses fichiers ensemble. Le fichier à ouvrir est `index.html`.

Pour conserver les deux plans sur GitHub Pages, placez ce nouveau dossier dans `par-genres/` du dépôt actuel : l’adresse sera alors `https://jeannoeldoux.github.io/Plan-Biblique-lecture-en-1-an/par-genres/`.

Vous pouvez aussi utiliser un dépôt distinct. Tous les chemins sont relatifs. Le suivi et les sauvegardes de ce plan sont distincts de ceux de l’ancien plan ; ne transférez pas les validations entre ces calendriers différents.

Les outils existants sont conservés : suivi, notes, archives annuelles, recherche, date de départ, sauvegarde et import, impression, favoris, lecteur unique, navigation audio, vitesse, minuteur, présentation mobile et installation. Le site et les références deviennent disponibles hors connexion après une première visite en HTTPS ; les textes bibliques et l’audio externes nécessitent Internet.

Voir `methode.html` pour les 365 jours, la répartition, les limites de l’audio par chapitre et les sources. La couverture des versets est contrôlée dans `controle-couverture.json`.

L’ancien plan et son archive conservée restent inchangés.
